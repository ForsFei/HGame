# RocoLab · 洛克对战实验室

《洛克王国：世界》社区规则的本地模拟项目，首版先提供无插图简洁界面。已接入 HGame 游戏库，地址为 **http://127.0.0.1:43170/games/roco-lab/**，不增加游戏端口。

## 启动

需要 Node.js 22+ 与 **Python 3.10+**。Python 部分仅使用标准库，不需要 pip 安装。双击本目录 `启动游戏.bat`，或在 HGame 根目录运行 `npm start`。修改后端代码后需重启游戏库。

如果 Python 没有加入 PATH，在启动前设置：

```powershell
$env:ROCO_PYTHON = 'C:\Python314\python.exe'
npm start
```

## 首版功能

- **单机预设人机**：随机练习、标准回合期望、战术风险评估。后两者模拟双方全部合法指令组合，以 MP、存活、HP 与能量评价回合后状态；战术策略对最坏结果加大权重。不是上游 MCTS，也不会读取玩家本回合提交的动作。
- **本地双人**：同屏依次提交，交接遮罩，双方动作齐备后统一执行；结算前不向网页返回已提交动作。
- **模型对战**：A 为玩家、B 为模型，支持 DeepSeek、OpenAI 和其他 Chat Completions 兼容接口。接口异常不推进对局，可重试或仅本回合用预设人机。需要填写对应服务商的 Key；ChatGPT 订阅不作为 API 凭据。
- **样本配置**：461 只精灵、491 个技能的本地快照，1–6 只队伍、学习关系校验、四技能、25 种性格、最多三项 +60 个体值、预设队伍、JSON 导入导出与队列调整。
- **伤害推导**：种族值推导或输入六项面板值、生命比例、能量、能力修正、天气、威力与连击覆盖。共用引擎的基础公式，并运行一回合效果引擎作 HP 净变化对照。
- **回合日志**：记录双方动作与所有精灵的 HP 变化，可导出对局 JSON。

## 数据版本和规则边界

核心来自 [ColinHong10/NRC_AI](https://github.com/ColinHong10/NRC_AI)，MIT 授权；固定提交 `9b5801b08d349c6505a233c513faa5075f427035`，2026-04-20。实际数据库为 461 只精灵、491 个技能，与上游 README 的部分数量不同，以实读数据库为准。

上游作者仍列有未覆盖特性、技能校验和伤害校准任务。已有效果配置不代表通过实机校准，本版不能保证与最新赛季一致。界面始终标明社区快照与特性覆盖状态。更详细的研究与移植记录见 [SOURCES.md](SOURCES.md)。

基础直伤为：`floor((攻击 / 防御) × 能力修正 × 威力 × 0.9 × 克制 × 本系 × 天气 × 连击)`。它不含条件威力、特性、应对、印记和持续效果；零威力技能直伤为 0。连击默认采用引擎字段，可手动覆盖。下方的回合对照显示完整回合的 HP 净变化，包含技能效果、回复、蓄力、持续伤害及防御侧指令。

对局初始 4 MP，常规倒下扣 1 MP；MP 归零或全队倒下结束，200 回合后平局。主动切换占用一回合。首版倒下接替、技能脱离与强制换人由上游引擎自动处理，暂不暂停回合让玩家额外选替补；上游各触发路径可能按队列或随机选择。

对局保存在规则进程内存中，服务重启即失效。闲置 3 小时的对局在新建对局时回收，最多保留 32 场；浏览器刷新可恢复仍在服务中的会话。样本配置保存在浏览器本地。

## 模型输入与日志

模型收到规则提示词、公开的双方队伍与技能说明、当前 HP/能量/能力修正、MP、场地印记、天气、最近 8 回合和 B 侧合法动作。它看不到 A 本回合的选择。只允许返回合法指令：

```json
{"action":[0],"reason":"简短决策说明"}
```

`[技能下标]` 使用技能，`[-1]` 聚能，`[-2,替补下标]` 切换。规则引擎负责判断合法性与结算，模型不能修改局面。

完整系统提示词在 `model-api.mjs` 的 `SYSTEM_PROMPT`。每次请求、响应、重试和最终动作写入 `logs/model-api-YYYY-MM-DD.jsonl`，日期按上海时区。密钥脱敏，日志忽略 Git 提交且不能通过网页静态路径读取。页面“模型调用”可查看、导出最近一次成功调用的提示词与原始输出。API Key 仅放在页面内存，刷新清除；基础地址与模型 ID 可保留。

真实付费服务未在开发时调用；通过模拟接口覆盖成功、非法动作重试、认证失败、密钥脱敏，以及失败不推进回合。

## 文件与验证

- `public/`：简洁页面、配队编辑与计算界面；不含权威规则状态。
- `worker.py`：JSON-lines 规则适配器与人机策略。
- `bridge.mjs`、`api.mjs`：现有 Node 进程调用 Python 子进程，只有 HGame 的 43170 一个监听端口。
- `vendor/nrc/`：保留所需引擎源码、1.2 MB SQLite 数据与 MIT 原授权，不包含上游 GUI、抓取工具、插图与网络辅助功能。
- `test/roco.test.mjs`：真实引擎对局、双人提交、公式手算样例、地系映射、模型协议与路由隔离测试。

在本目录执行 `npm test`，或 HGame 根目录 `npm test` 运行全部游戏测试。

后续先核对常用精灵与技能的规则和版本，再加入完整版美术与演出；简洁界面与完整版共用本套规则。
