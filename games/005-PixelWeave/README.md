# 像素织图 · PixelWeave · HGame 005

> **统一入口（已整理）**：从游戏库根目录双击 `启动游戏库.bat`，地址为 `http://127.0.0.1:43170/`；本游戏地址为 `http://127.0.0.1:43170/games/pixel-weave/`。本目录的 `启动游戏.bat` 和 `npm start` 也使用同一个游戏库服务。旧独立端口已停用，下面旧版记录中的端口仅供历史参考。无需单独启动此游戏。


数织（Nonogram）玩法的原创小游戏：按行、列的数字线索还原一张隐藏的像素图。所有关卡都由脚本生成并逐题验证唯一解，不使用第三方题包、联网或模型调用。

## 启动

需要 Node.js 22+，无需安装依赖。双击本目录 `启动游戏.bat` 打开游戏；已运行游戏库时会复用。也可在游戏库根目录运行 `npm start`，统一端口 43170。规则测试仍在本目录运行 `npm test`。如需临时更换整个游戏库端口，可在根目录设置 `$env:PORT=44170` 后运行 `npm start`。

## 怎么玩

1. 点击或按住拖动格子涂黑；再次点击同一格会变成「×」，表示确定为空，再点一次回到空白。
2. 右键或长按直接标 ×，用于推理时做草稿。
3. 行、列开头的数字表示该方向连续涂黑的长度与顺序。例如 `3 1` 表示先连续三格黑、至少空一格、再一格黑。
4. 某一方向填对后，它开头的数字会变暗，提示这条线索已经满足。
5. 所有格子的涂黑状态与线索完全一致时自动判定完成。

「检查」会标出与答案不符的涂黑格，两秒后自动消失；它不会直接给出答案。「撤销」支持按钮与 Ctrl+Z，「清除」需要自己确认后重来。

## 关卡

共 30 题：12 题 5 × 5（带图案名，如小船、钥匙、心形）、12 题 10 × 10、6 题 15 × 15。

10 × 10 与 15 × 15 的题目由 `scripts/generate.mjs` 生成：先随机叠加若干椭圆形成有机形状，再扰动少量像素，然后用内置求解器计数解的数量，只保留恰好一个解的题目。生成过程固定随机种子，结果写入 `public/puzzles.js`，可重复执行 `npm run generate` 重新生成。测试会逐题复验唯一性，所以改动关卡时不会悄悄引入多解题。

## 每日挑战

按北京时间日期从 10 × 10 题库中选一题，同一天打开都是同一张图，跨零点更换。当天第一次完成的结果会计入记录，重做不会覆盖当天成绩。练习模式可自由选择 5 × 5、10 × 10、15 × 15。

## 简洁模式（摸鱼模式）

点击「简洁模式」或按 **Alt+M**，切换为浅色等宽的工作台：标题变成「位图索引」，标签页改为「位图索引 · 本地」，隐藏品牌与装饰，直角、无阴影、无动画。它不只是换配色——**棋盘会直接变成 0/1 矩阵**：置位显示 `1`，清零显示 `0`，配合纯数字的行列索引，整体看起来就是一张位图配置表。

术语全部落在计算机领域：

| 标准模式 | 简洁模式 |
| --- | --- |
| 像素织图 | 位图索引 |
| 每日挑战 | 每日批次 |
| 新的一局 | 新建批次 |
| 织格 | 矩阵 |
| 棋盘规模 | 矩阵规模 |
| 行 / 列线索 | 行索引 / 列索引 |
| 涂黑 | 置位 1 |
| 标记 × | 置位 0 |
| 已涂黑 12 / 39 | 已置位 12 / 39 |
| 检查 | 校验 |
| 撤销 / 清除 | 回退 / 清空 |
| 下一关 | 下一批次 |
| 本地记录 | 运行记录 |
| 织好了 | 生成完成 |

为了不牺牲可读性，手册里仍然把规则写成「行、列开头的数字表示连续 1 的长度与顺序，例如 3 1 表示连续三位 1、至少空一位、再一位 1」，不需要先理解术语。切换不改变进度、已画的格子和当前选择，模式记在本地，刷新保持。

## 存档与记录

- `pixelweave-save`：当前一局的隐藏答案、每个格子的状态、模式与日期，刷新或关闭后继续。
- `pixelweave-records`：最近 50 条完成记录，含题目、规模、模式与日期，每日挑战每天只记一条。
- `pixelweave-view`：上次使用的视图模式。

存档格式异常时自动开始新局。清除浏览器数据会丢失进度与记录，不含联网排名。

## 结构

- `server.mjs`：本地静态服务，只监听 `127.0.0.1`。
- `public/engine.js`：线索计算、行候选、解计数求解器、棋盘状态、唯一解校验、每日选题与记录统计。
- `public/puzzles.js`：30 道关卡数据（生成产物，勿手改）。
- `public/app.js`：界面渲染、指针拖拽与长按、撤销、双视图切换。
- `public/style.css`：标准视图与位图索引视图两套主题。
- `scripts/generate.mjs`：关卡生成与唯一解筛选。
- `test/engine.test.mjs`：线索、候选组合数、求解器、关卡池唯一性、状态流转、存档防篡改、每日选题、记录去重与统计。

## 验证

`npm test` 共 12 项测试：线索计算覆盖空行、满行与多段；行候选数量与组合数一致；求解器能区分唯一解和多解样例；30 道关卡全部合法且唯一解；标记三态循环与越界拒绝；只填对黑格即可完成（× 只是草稿）；`mistakes` 只报告涂错的格子；存档被篡改（尺寸、长度、非法状态、答非所问的完成标记）时 `validSave` 返回否，正常存档可跨刷新继续；每日选题同日一致且北京时间零点换题；练习选题遵守规模并避开当前题；每日记录每天只保留一条；统计按模式与规模汇总。

`public/engine.js` 与 `public/puzzles.js` 都不依赖界面，`public/app.js` 只负责显示与交互。
