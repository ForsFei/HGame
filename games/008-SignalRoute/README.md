# 信号路由 · SignalRoute · HGame 008

> **统一入口（已整理）**：从游戏库根目录双击 `启动游戏库.bat`，地址为 `http://127.0.0.1:43170/`；本游戏地址为 `http://127.0.0.1:43170/games/signal-route/`。本目录的 `启动游戏.bat` 和 `npm start` 也使用同一个游戏库服务。旧独立端口已停用，下面旧版记录中的端口仅供历史参考。无需单独启动此游戏。


接线主题的解谜：棋盘是一张被打散的管网，旋转每块线路，把每个节点接回网关。每次开局都保证有解，不需要靠运气。界面为原创，无外部字体、图片、联网或模型调用。

## 启动

需要 Node.js 22+，无需安装依赖。双击本目录 `启动游戏.bat` 打开游戏；已运行游戏库时会复用。也可在游戏库根目录运行 `npm start`，统一端口 43170。规则测试仍在本目录运行 `npm test`。如需临时更换整个游戏库端口，可在根目录设置 `$env:PORT=44170` 后运行 `npm start`。

## 玩法

1. 左键点击线路：顺时针旋转 90 度；右键点击或触摸长按约 0.45 秒：逆时针旋转 90 度。
2. 键盘操作：Tab 聚焦到格子后按 Enter 或空格顺时针旋转，按住 Shift 则逆时针。
3. 每块线路的接口必须与相邻线路的接口对上；橙色表示这一端悬空。
4. 全盘没有断口、并且所有格子连成一片时通关，断开的孤岛不算完成。
5. 带方点的两格是网关，锁死不可旋转，可以用来对位参照。
6. 步数统计每一次有效旋转，计时从第一次旋转开始，通关后冻结。

三档规模：

| 范围 | 尺寸 | 开局断口（均值） | 生成耗时 |
| --- | --- | --- | --- |
| 小型 | 6 × 6 | 42.5 | 0.10 ms/局 |
| 中型 | 7 × 7 | 54.7 | 0.10 ms/局 |
| 大型 | 8 × 8 | 74.4 | 0.05 ms/局 |

数据来自 `npm run probe` 每档 20 局的抽样。

## 生成方式与可解性

1. 用随机 DFS 在网格上生成一棵覆盖全部格子的生成树，树边就是「解」里的管网。
2. 两格网关保留解的朝向并锁定，其余每格随机顺时针旋转 1–3 次（保证不是原样）。
3. 若打散后恰好仍是完成态，会把其中一格再转 90 度，确保开局一定有活可干。

因此每一局都必然有解：把每格转回解的朝向即可。**但它不是唯一解**——可能存在另一种同样「无断口且连成一片」的形态，游戏判定只看连通与断口，不要求与生成时的解逐格一致；这一点与扫雷类「唯一解」要求不同，也是接线类谜题的常规做法。

## 进度反馈

- 已接通的线路变成青色（简洁模式下是蓝色），未接通保持灰色。
- 断口用橙色标出，但**只标在已接通的线路上**，所以开局不会满屏橙色，橙色始终出现在你正在修的那一圈。
- 顶部提示行实时显示「已接通 X/Y 个节点，还有 N 处断口」。

## 计时与战绩

- 每档分别记录最佳用时与最少步数，侧栏显示两者。
- 战绩保留最近 50 条，同一局只记一次，重复刷新不会重复计数。
- 时间按 `startedAt` 与 `finishedAt` 的真实时间差计算，精度到秒。

## 简洁模式（摸鱼模式）

点击「简洁模式」或按 **Alt+M**，切换为浅色等宽工作台：标题变成「链路巡检」，浏览器标签页改为「链路巡检 · 本地」，品牌位换成 `LOCAL SESSION`，直角、无阴影、无动画，配色沿用 `shared/quiet.css` 的公共契约。进度、步数、计时与战绩全部保留，再次点击「标准视图」或按 Alt+M 返回。

## 存档

- `signalroute-save`：当前一局，含每格接口位掩码、锁定的网关、步数、状态、开始与结束时间。
- `signalroute-records`：最近 50 条战绩，含范围、尺寸、秒数、步数与完成时间。
- `signalroute-view`：上次使用的视图模式。

`validSave` 校验版本、范围与尺寸、接口掩码必须是 0–15 的整数、锁定数组必须是布尔、步数是非负整数、状态取值与时间戳：`ready` 必须是零步且无结束时间，`playing` 必须已走过步数、没有结束时间且尚未完成，`won` 必须已处于完成态。

## 结构

- `server.mjs`：本地静态服务，只监听 `127.0.0.1`，白名单提供 5 个前端资源。
- `public/engine.js`：无 DOM 依赖的规则内核：方向步进、旋转、断口统计、连通判定、生成器、开局、旋转落子、计时、存档校验、战绩汇总。
- `public/app.js`：界面渲染（管道由绝对定位的线段拼出）、指针与键盘操作、对话框、存档读写、双视图文案。
- `public/quiet.js`、`public/quiet.css`：简洁模式公共实现的副本，与 `shared/` 保持一致。
- `public/style.css`：标准（深色接线台）与巡检两套主题。
- `scripts/probe.mjs`：三档规模的生成耗时、开局断口与开局完成率抽样。
- `test/engine.test.mjs`：规则测试。

## 验证

`npm test` 共 11 项：旋转四次回到原状、反向旋转等价；边界步进返回 `-1`；断口只统计没对接的接口；完成态接受闭环、拒绝「无断口但分成两座孤岛」；生成器覆盖每格、网关保留解的朝向、解本身连通、开局一定未完成；锁定格旋转返回 `false` 且不计数，越界抛 `index`；转完最后一格由 `playing` 转为 `won` 并冻结时钟，结束后继续操作抛 `ended`；存档校验拒绝非法尺寸、掩码越界、锁定值非布尔、`playing` 带结束时间等畸形存档；同一局只记一条并按档汇总最佳用时与最少步数；三档范围的尺寸与标识一致。

`public/engine.js` 不碰 DOM，`public/app.js` 只负责显示与交互。
