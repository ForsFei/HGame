# 词条校验 · WordCheck · HGame 004

> 游戏入口：http://127.0.0.1:43170/games/word-check/ · [统一启动说明](../../README.md)

编程主题的猜词小游戏：6 次机会猜出一个 5 位英文标识符，逐位得到命中提示。词库全部是编程领域的常用词，界面为原创，不使用第三方词库、联网或模型调用。

## 启动

需要 Node.js 22+，无需安装依赖。双击本目录 `启动游戏.bat` 打开游戏；已运行游戏库时会复用。也可在游戏库根目录运行 `npm start`，统一端口 43170。规则测试仍在本目录运行 `npm test`。如需临时更换整个游戏库端口，可在根目录设置 `$env:PORT=44170` 后运行 `npm start`。

## 怎么玩

1. 页面顶部会显示本题的**词域**（如「数据结构」），先按领域回忆标识符，比随机猜有效得多。
2. 输入 5 个英文字母，按回车提交；也可以用屏幕键盘。
3. 每个字母给出一种标记：位置正确、词里有但位置不对、词里没有。
4. 6 次之内猜中即通过，用完 6 次仍未猜中则失败，并公布答案。

目标词全部是编程领域的 5 字母常用词，例如 `class`、`cache`、`query`、`nginx`。词库共 130 余个，按语言与语法、数据结构、网络与接口、进程与系统、数据库、工程与界面六个词域分组，每题的词域会显示在标题右侧。

重复字母按词中实际数量匹配：答案里某个字母只出现一次时，即使猜测里写了两次，也只会有一个位置得到「存在」标记。

### 词库外的词

不在词库里的 5 字母组合（例如 `notes`）同样可以提交并正常比对，只会标注「未声明标识符」或「这个词不在词库」。这样可以自由试探字母，不会被输入校验卡住；代价是不再具有「必须是真实单词」的约束。

## 每日挑战与练习

- **每日挑战**按北京时间日期生成固定词条，同一天打开都是同一题，跨零点自动更换。当天第一次完成的结果会进入统计，重玩不会覆盖当天记录。
- **练习模式**随机出题，可随时用「新的一局」重开。
- 一局进度自动保存，刷新或关闭页面后继续，不需要登录。

## 简洁模式（摸鱼模式）

点击「简洁模式」或按 **Alt+M**，切换为浅色等宽的工作台界面：标题变成「标识符校验」，浏览器标签页改为「构建日志 · 本地」，隐藏品牌与装饰，使用直角、无阴影、无动画的低对比配色。玩法、进度、已提交的行与当前输入全部保留，再次点击「标准视图」或按 Alt+M 返回。模式记在本地，刷新后保持。

术语整体落在计算机与代码领域，而不是报表或指标：

| 标准模式 | 简洁模式 |
| --- | --- |
| 词条校验 | 标识符校验 |
| 每日挑战 | 每日构建 |
| 新的一局 | 新会话 |
| 尝试记录 | 比对结果 |
| 还剩 4 次 | 剩余预算 4 |
| 第 3 / 6 次 | 重试 3 / 6 |
| 位置正确 | 位匹配 |
| 词里有，位置不对 | 符号存在 · 偏移不符 |
| 词里没有 | 未出现 |
| 词域 | 命名空间 |
| 这个词不在词库 | 未声明标识符：已按字节逐位比对 |
| 本地战绩 | 运行记录 |
| 猜中了 / 没猜中 | 校验通过 / 校验失败 |
| 答案是 | 目标标识符 |

同时保留可读性：说明文案仍写「输入 5 位标识符后按 ENTER」「6 次内完成逐位比对」，不要求使用者先懂终端术语。简洁模式只改变当前页面的显示，不隐藏浏览器地址、标签页标题以外的系统信息、历史记录或任务栏。

## 存档与战绩

- `wordcheck-save`：当前一局，包含答案、已提交的行与标记、模式、日期。存档格式异常时自动开始新的一局。
- `wordcheck-records`：最近 50 条结果，含模式、日期、答案、使用次数与胜负。统计展示完成数、通过率、最近连续通过次数与 1–6 次分布。
- `wordcheck-view`：上次使用的视图模式。

每日挑战每天只记录一条；练习模式每局一条，同一局不会重复记账。中途刷新不会重复记录。清除浏览器数据会清空进度与战绩，不含联网排名。

## 结构

- `server.mjs`：统一游戏库启动入口，复用根目录服务。
- `public/engine.js`：词库、反馈算法、回合状态、每日选题、存档与统计校验。
- `public/app.js`：界面渲染、键盘输入、模式切换、存档读写。
- `public/style.css`：标准视图与简洁视图两套主题。
- `test/engine.test.mjs`：词库完整性、重复字母、提交限制、每日稳定性、跨日边界、存档防篡改、记录去重与统计。

## 验证

`npm test` 共 9 项测试：词库全部为 5 位小写字母且不重复、分类齐全；反馈算法覆盖重复字母与多命中情形；提交顺序、重复词、长度、次数用尽与结束后操作均被拒绝且状态不变；每日答案同日一致、跨日有差异；北京时间零点正确换题；存档被篡改（答案、标记、状态、重复行）时 `validSave` 返回否，正常存档可跨刷新继续；每日记录只保留一条；统计的通过率、连续次数与分布计算正确。

`public/engine.js` 为无界面依赖的规则模块，`public/app.js` 只负责显示与交互。不读取网络、不请求外部字体或图片。
